# Youth Week 2026

A browser-based **I Will Be Attending** badge generator for the Christ Apostolic Mission Church (Oke Igbala) Youth Anniversary.

## Setup

1. Save the supplied Youth Anniversary flyer in this repository as `youth-anniversary-poster.jpg`.
2. Enable GitHub Pages in **Settings → Pages**, selecting the `main` branch and `/ (root)` folder.
3. Share the published URL:
   `https://sjb-tech.github.io/youth-week-2026/`

Visitors can upload a photo, preview the badge, and download the completed PNG. Photos are processed locally in the visitor’s browser and are not sent to a server.
