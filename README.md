# Youth Week 2026

This repository contains a simple browser-based badge generator for the Youth Anniversary event.

## Preview

Open the page in a browser and upload a photo to generate a custom **I Will Be Attending** badge.

## GitHub Pages

1. Go to the repository's **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
4. Save.

Your live site will be available at:

`https://sjb-tech.github.io/youth-week-2026/`

## Files

- `index.html` – page with photo upload and download function
- `poster.svg` – poster-style background design for the badge

The uploaded photo is processed locally in the browser and is not sent to a server.
